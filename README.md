# Engineering Principles

Shared coding principles for clear control flow, justified abstractions, explicit invariants, and focused changes.

## Install

```bash
npx skills add auaa-x/engineering-principles --global
```

Install non-interactively for all supported agents:

```bash
npx skills add auaa-x/engineering-principles --all --global
```

The skill is intentionally language- and framework-agnostic. Frontend-specific guidance can be added separately.
